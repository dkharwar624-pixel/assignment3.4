I converted my existing div-based webpage into semantic HTML to improve accessibility and SEO. I replaced the generic div tags with meaningful semantic tags. I structured the page using <header> for the website identity, <nav> for keeping all navigation links inside it, <main> to wrap the main content of the page, <section> for distinct sections like About, Education, and Skills, <article> for independent content like a blog post, <aside> for extra related information and useful links, and <footer> for contact and copyright information. I maintained a correct heading hierarchy from h1 for the main name, h2 for section titles, and h3 for sub-titles. I also added meaningful alt text for images, such as describing the person's appearance and context instead of just writing "profile photo". Finally, I checked that all links and page sections were clearly understandable and accessible for both users and screen readers.
